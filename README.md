# Tuntematon ilmasto · Unknown Climate

*Unknown Climate: a climate negotiation game under uncertainty*

Interactive classroom demo on climate negotiations and the Paris Agreement, for players from
grade 7 upwards, including adults. It is meant to be led by a teacher or other presenter;
younger players need more help from the presenter.
Built with [Streamlit](https://streamlit.io/) and the [FaIR v2.2](https://docs.fairmodel.net/) climate model.

## What it does

Students are divided into five groups, each representing a major emitting region:
**China, USA, EU, India, Rest of World**.

The game runs as a sequence of screens. Its second theme is uncertainty: the climate
sensitivity of the simulated Earth is unknown to the players and has to be learned.

1. **Pledges** — each group sets a fossil CO₂ cut for 2040, relative to 2025 emissions.
2. **Prior estimate** — histograms of ECS and end-of-century warming (20-year mean 2090–2109)
   over the whole model ensemble, with the probability of exceeding 1.5, 2, 3 and 4 °C.
3. **Draw** — one ensemble member ("one possible Earth") is drawn at random. Its ECS stays
   hidden, and the pledges are locked.
4. **Simulation to 2040** — FaIR run of the drawn member. The single year 2040 is shown next to
   the 20-year mean centred on 2040 (2030–2049; the years after 2040 are projected).
   The Paris thresholds are judged on 20-year means, as IPCC warming levels are.
5. **Observation 2040** — the observed 2031–2040 mean updates the estimates (Bayesian
   reweighting of the ensemble). Usually this narrows them only a little.
6. **Research advances** — a noisy research estimate of ECS narrows them clearly.
7. **Net-zero years** — each group decides when their region's CO₂ emissions reach net zero,
   using the updated estimates. A second FaIR run shows the trajectory to
   peak warming, judged on the peak of the 20-year running mean.
8. **Reveal** — the drawn Earth's true ECS and 2090–2109 mean warming against the estimates.

An impacts page (what 1.5–4 °C means globally and in Finland, with the probability of each
level under the players' decisions) can be opened from every screen. All temperatures are
annual means relative to 1850–1900.

## Climate model

Each game session draws one configuration at random from a pre-screened shortlist of
FaIR posterior ensemble members (fair-calibrate v1.6.0, FaIR 2.2.4; 841 members).
Screening is only for visual continuity with the observations: a member is kept if its 2026
annual-mean temperature is within about 0.25 °C of the mean of the observed (IGCC-2025a) 2023–2025
temperatures. The rule and its rationale are documented in `precompute_configs.py`.
Only fossil (fuel and industry) CO₂ is set by the players. Observed global totals are used for
2023–2024 and regional baselines for 2025 (Global Carbon Budget, via Our World in Data).
Land-use CO₂ and all non-CO₂ forcing follow the SSP2-4.5 scenario throughout.
Runs are stochastic with fixed per-member seeds, so a member always gives the same curve.

## Caveats

- **An educational tool, not a projection.** The game is designed to build a conceptual
  understanding of climate uncertainty: how much warming depends on an unknown climate
  sensitivity, and how observations and research gradually narrow it. Its numbers are not
  projections and should not be used for policy, planning or research.
- **The climate is simplified, and the evidence is synthetic.** Players control only fossil
  CO₂. Land-use CO₂ and all other forcing follow SSP2-4.5. Each game is one FaIR ensemble member
  with one fixed realisation of natural variability. The 2040 "observation" and the research
  estimate of climate sensitivity are random values generated by the game. Their uncertainties
  (0.05 °C and 0.5 °C) are design choices. The research estimate is deliberately more precise
  than today's IPCC assessment, to show what future research could achieve.
- **The probabilities depend on the model.** Warming estimates and exceedance probabilities
  come from the fair-calibrate ensemble, screened for continuity with recent observations. They
  are not IPCC likelihood statements.
- **Impacts are indicative only.** The impact descriptions for each warming level are rounded,
  simplified figures for classroom discussion. They draw loosely on IPCC reports and Finnish
  sources, but they are not a rigorous synthesis of the research literature.
- **Pledge options and decarbonisation rates are largely hand-picked.** The regional pledge
  levels and net-zero timings were chosen to make the game playable. They are not based on
  rigorous analyses of what is feasible or fair for each region, although they try to show different capabilities. They can be misleading and may raise ethical questions, for example about historical responsibility, capacity and equity between
  regions. Emissions are territorial fossil CO₂ for five regions, from 2025 data.
- **AI-assisted code.** The code was written with the help of Claude (Anthropic) and then
  results and interface were reviewed by the author. The code may contain errors or omissions. Please report problems as GitHub issues.
- **Not peer reviewed and not an official FMI position.** The game has not been peer
  reviewed. Its simplifications and framing are the author's and do not represent official views
  of the Finnish Meteorological Institute.
- **For teachers:** these caveats are worth discussing with students after a game, as part
  of the lesson on uncertainty.

## Privacy

The game asks for no names or other personal information and has no text fields. Choices made
during a game exist only in the server's memory for that browser session; nothing is saved to
files or a database, and the game itself sends nothing to other services.

The public version runs on [Streamlit Community Cloud](https://streamlit.io/cloud), which hosts
apps in the United States. Streamlit (Snowflake) collects anonymous usage statistics and keeps
standard server logs, as described in the
[Streamlit privacy notice](https://streamlit.io/privacy-policy). If the app is shared only with
invited viewers, they sign in to Streamlit, so Streamlit knows their email address.

## Setup

### Prerequisites

- Python 3.11 (3.12 also works)
- fair-calibrate v1.6.0 data, included in `data/fair_calibrate/` (see the README there)

### Install

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` pins the versions the app is tested with; Streamlit Community Cloud installs
from it. For development with Mamba or Conda (Python 3.11 from conda-forge) there is
`environment-dev.yml`:

```bash
mamba env create -f environment-dev.yml
mamba activate climate-game
```

### Pre-compute screened configs (once)

```bash
python precompute_configs.py
```

This writes `data/screened_configs.csv` (736 configs) and `figures/screening_diagnostics.png`.
Re-run if you change the screening criteria. The CSV is committed so the app starts from a fresh clone.

### Run

```bash
streamlit run app.py
```

Open the printed URL in a browser (or project it for the class). For the instructor mode with
free sliders instead of four options per region, add `?mode=sliders` to the URL
(e.g. `http://localhost:8501/?mode=sliders`).
